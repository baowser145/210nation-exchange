# The 210Nation Exchange

NBA player stats tracked like a stock exchange: a scrolling ticker tape, hot/cold
"price" moves, sparklines, and full-season charts for every rotation player (15+ min, 8+ pts).

A player's price is their last-10-game average for the chosen stat; the change is
that form measured against their season average. Data comes from ESPN's public
API, fetched live on page load, with a baked-in season snapshot as fallback.

Unofficial, non-commercial fan project.
